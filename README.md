# zmk-config-chitin
This repository contains the ZMK firmware for chitin, including the PIM447 driver for the trackball. This repository is pinned to ZMK v0.3.0. Fork this repository to make changes to your personalized chitin keyboard.

Examples of customizations include:
- Modify the keymap easily by using the [ZMK Keymap Editor](https://nickcoutsos.github.io/keymap-editor/) browser app by nickcoutsos, or by manually by editing config/chitin.keymap
- Modify ZMK configurations by editing config/chitin.conf
- Modify trackball configurations by editing boards/shields/chitin/chitin_right.overlay
